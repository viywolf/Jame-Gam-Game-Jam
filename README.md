# Raise A Lil Guy!
Raise A Lil Guy! is a game where you make choices to raise your creature, and can try to unlock every creature variant by exploring the choices. Play it on [itch.io](https://viywolf.itch.io/raise-a-lil-guy).

![](https://github.com/viywolf/Jame-Gam-Game-Jam/blob/main/assets/logo.png)

The game features 39 different creatures, with a helpful menu to check which ones you've unlocked so far.

The game is made in Godot. All art was made by [clov3r_leaf](https://github.com/clov3r-leaf). Programming and music was made by [viywolf](https://github.com/viywolf).

This project was a submission to the Jame Gam Game Jam by Hack Club.
